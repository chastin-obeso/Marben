# MBR-E-Marben
Marben is a company management system web application tailored for MBR-E Concepts Computer Services.

## About the Company
The company was founded by Corazon Roxas and has been In operation since
2008. It mainly comprises four types of services: repair, layouting,
printing/binding, and software development.

## App Features
1. User Management
2. Job Order Management
3. Billing and Payment Management

## Installation
1. Pull the Repo
2. Create an .env file from .env-example and change the db accordingly
